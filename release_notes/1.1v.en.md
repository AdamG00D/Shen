## Download

| File | For |
|---|---|
| `Shen-1.1-arm64-v8a.apk` | **Most phones** (2017 and newer) — pick this if unsure |
| `Shen-1.1-armeabi-v7a.apk` | Older or low-end phones |
| `Shen-1.1-x86_64.apk` | Emulators and Chromebooks |
| `Shen-1.1-universal.apk` | Any device (larger download) |

All variants share the same version code, so you can update from any of them to any other. Android 8.0+.
Verify with the release key ([docs/shen-release-key.asc](https://github.com/AdamG00D/Shen/blob/main/docs/shen-release-key.asc),
`B2D4 53B8 5430 D721 C173 3C1F B0E8 ADA6 3BD7 84BC`):

```bash
gpg --verify SHA256SUMS.txt.asc SHA256SUMS.txt && sha256sum -c SHA256SUMS.txt --ignore-missing
```

## What's new

- **A look of its own — "stone and seal"**: limestone (basalt in dark mode), ink buttons, brass only for the marks
  that matter.
- **New icon**: a brass shen ring on basalt.
- Key owners' names and the profile switcher sit in a **cartouche**.
- Signature results are a clear **seal**: green = good and verified, brass = good but the key isn't verified yet,
  red = bad.
- Fingerprints are shown as a grid in a monospaced font, easier to compare.
- The accent colour picker is gone: one identity, light and dark.

## Fixes

- Saved files keep their name (`key.asc` used to be saved as `key.asc.key`).
- A wrong password for a password-encrypted message is always reported as a wrong password.
- New keys protect every subkey with its own salt.
- Ubuntu 26.04 only: after importing your secret key into gpg, run `gpg --passwd` once (a libgcrypt 1.12.0 bug there).
