## Download

| File | For |
|---|---|
| `Shen-1.2-arm64-v8a.apk` | **Most phones** (2017 and newer) — pick this if unsure |
| `Shen-1.2-armeabi-v7a.apk` | Older or low-end phones |
| `Shen-1.2-x86_64.apk` | Emulators and Chromebooks |
| `Shen-1.2-universal.apk` | Any device (larger download) |

All variants share the same version code, so you can update from any of them to any other. Android 8.0+.
Verify with the release key ([docs/shen-release-key.asc](https://github.com/AdamG00D/Shen/blob/main/docs/shen-release-key.asc),
`B2D4 53B8 5430 D721 C173 3C1F B0E8 ADA6 3BD7 84BC`):

```bash
gpg --verify SHA256SUMS.txt.asc SHA256SUMS.txt && sha256sum -c SHA256SUMS.txt --ignore-missing
```

## What's new

- **Sign** and **Also encrypt to myself** now start off when encrypting — turn them on when you want them.
- When you have no key that can sign or receive, the option says why.
- After unlocking you're back on the tab you were on (nothing you had typed is kept — that is wiped with the lock).

## Fixes

- Immediate auto-lock asked for the fingerprint twice when coming back to the app.
- Copy / Share / Save button labels were cut off on narrow phones.
- Turning on **Sign** picks your default key only if it can sign, otherwise the first key that can.
